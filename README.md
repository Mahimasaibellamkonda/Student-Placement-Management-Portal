# CampusHire - Student Placement Management Portal

CampusHire is a professional web-based Student Placement Management Portal designed to simplify the campus recruitment process for students and placement officers.

The system allows students to explore job opportunities, check eligibility, apply for companies and track their application status.

---

## Project Objective

The main objective of this project is to develop a centralized placement management platform where:

- Students can view placement opportunities.
- Students can check company eligibility criteria.
- Students can apply for suitable jobs.
- Students can track application status.
- Placement officers can add and manage job opportunities.
- Placement information can be maintained digitally.

---

## Features

### Student Features

- Student dashboard
- Student profile
- Academic information
- CGPA-based eligibility checking
- Technical skills display
- Job opportunity search
- Location filtering
- Role filtering
- Job details
- Apply for jobs
- Application tracking
- Application status
- Placement activity timeline

### Placement Cell Features

- View registered recruiters
- View available job openings
- View total applications
- Add new placement opportunities
- Remove opportunities
- Set minimum CGPA
- Define required technical skills
